## Tech Stack

* **React 18** — UI built with reusable JSX components.
* **Vite 5** — Build tool and development server with `@vitejs/plugin-react`.
* **Tailwind CSS 3** — Utility-first styling with PostCSS and Autoprefixer. Brand colors, Urbanist font, animations, and background images are configured in `tailwind.config.js`.
* **React Router 6** — Client-side navigation using `BrowserRouter` with nested routes under a shared layout.
* **React Icons** — Font Awesome 6 icons via `react-icons/fa6`, replacing Bootstrap Icons and Font Awesome.
* **Embla Carousel** — Property and testimonial sliders, including gallery thumbnails, using `embla-carousel-react` with the autoplay plugin.

### Additional Features

* **IntersectionObserver** — Scroll-reveal animations.
* **React Portal** — Lightbox implementation.
* **React useState** — Contact form state management.
* **CSS Smooth Scroll** — Smooth scrolling with `scroll-behavior` and a custom `ScrollManager` component for anchor links.

The project uses plain React with no unnecessary external libraries.
